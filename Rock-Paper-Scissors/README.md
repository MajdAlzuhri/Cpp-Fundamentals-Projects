# Rock Paper Scissors Game

A simple console-based Rock Paper Scissors game built with C++. The player competes against the computer over a selected number of rounds, and the program displays the result of every round and the final winner.

## Features

- Choose the number of rounds.
- Play against a computer-generated random choice.
- Determine the winner of each round.
- Track player wins, computer wins, and draws.
- Display a final game summary.
- Change the console color according to the result.
- Restart the game without closing the program.

## Concepts Practiced

- Functions
- Enums
- Structs
- Loops and conditional statements
- Random number generation
- Input validation
- Passing structures by reference
- Separating game logic into reusable functions

## How to Run

1. Open the project in Visual Studio or another C++ IDE.
2. Create a C++ Console Application.
3. Replace the generated source code with the contents of `main.cpp`.
4. Build and run the project.

> The console color and clear-screen commands are designed for Windows.
