# C++ Fundamentals Projects

A collection of small console applications created while practicing structured programming and fundamental C++ concepts.

## Projects

### Rock Paper Scissors Game

A multi-round game between the player and the computer. It uses random computer choices, determines the winner of each round, and displays the final game statistics.

[Open the project](./Rock-Paper-Scissors)

### Math Quiz Game

A configurable quiz that generates random arithmetic questions based on the selected difficulty level and operation type, checks the answers, and displays the final result.

[Open the project](./Math-Quiz-Game)

## Main Concepts

- Functions
- Enums and structs
- Arrays
- Loops and conditions
- Random number generation
- Input validation
- Passing values and structures by reference
- Organizing a program into reusable functions
