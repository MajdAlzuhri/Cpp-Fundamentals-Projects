# Math Quiz Game

A console-based math quiz game developed with C++. The program generates random questions based on the difficulty level and arithmetic operation selected by the player, checks every answer, and displays a final result summary.

## Features

- Select between 1 and 100 questions.
- Choose Easy, Medium, Hard, or Mixed difficulty.
- Choose Addition, Subtraction, Multiplication, Division, or Mixed operations.
- Generate questions randomly.
- Check answers immediately.
- Display the correct answer after a mistake.
- Track correct and incorrect answers.
- Display a Pass or Fail result.
- Restart the quiz without closing the program.

## Concepts Practiced

- Functions
- Enums
- Structs
- Arrays
- Loops and conditional statements
- Random number generation
- Input validation
- Passing structures by reference
- Separating quiz logic into reusable functions

## How to Run

1. Open the project in Visual Studio or another C++ IDE.
2. Create a C++ Console Application.
3. Replace the generated source code with the contents of `main.cpp`.
4. Build and run the project.

> The clear-screen command is designed for Windows.
